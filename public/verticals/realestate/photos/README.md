the brand mark in that kit were not approved for use and are not here; this
vertical's icons and brand mark are original work, matching how the CA
vertical's icon set and BrandMark component were built).

project, a real building, or a real location, and must never be captioned with
a real developer or project name — the source kit's own documentation warns
against exactly that. Treat every file here as generic atmosphere/demo
artwork for a template, not as a claim about any actual property.
